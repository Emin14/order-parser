## Order Parser: быстрый запуск

Проект использует отдельный профиль браузера. В нём будут свои вкладки, история, cookies и авторизации. Личные вкладки обычного Яндекс.Браузера не затрагиваются.

### 1. Указать браузер в `.env`

В корне проекта создайте файл `.env` и добавьте строку:

```dotenv
BROWSER_PATH='C:/полный/путь/к/browser.exe'
```

Чтобы узнать путь:

1. Найдите Яндекс.Браузер или другой Chromium-браузер в меню «Пуск».
2. Откройте свойства его ярлыка.
3. На вкладке «Ярлык» скопируйте из поля «Объект» путь.
4. Вставьте этот путь в `BROWSER_PATH`.


### 2. Создать рабочий ярлык

Дважды щёлкните `create-browser-shortcut.cmd` в папке проекта.

В этой же папке появится ярлык **«Браузер — Заказы»**. Он открывает браузер с профилем `order-parser-profile`, который создаётся рядом с проектом автоматически.

Откройте ярлык **«Браузер — Заказы»** и один раз войдите в WhatsApp Web, Telegram Web K и VK. Входы сохранятся в отдельном рабочем профиле.

### 3. Запустить сбор заказов

Перед запуском закройте окно **«Браузер — Заказы»**, чтобы профиль не был занят другим процессом.

В терминале перейдите в папку проекта и выполните:

```powershell
npm start
```

Парсер сам откроет тот же браузерный профиль и использует сохранённые авторизации. Обычный личный браузер можно оставить открытым.

### Что создаётся автоматически

- `order-parser-profile\` — рабочий профиль браузера;
- `Браузер — Заказы.lnk` — ярлык рабочего браузера.

Эти файлы относятся к конкретному компьютеру и не должны переноситься через Git. При переносе проекта на другой компьютер укажите местный `BROWSER_PATH` и заново запустите `create-browser-shortcut.cmd`.
