## Order Parser: быстрый запуск

Проект использует отдельный профиль браузера. В нём будут свои вкладки, история, cookies и авторизации. Личные вкладки обычного Яндекс.Браузера не затрагиваются.

### 1. Указать браузер в `.env`

В корне проекта создайте файл `.env` и добавьте строку:

```dotenv
BROWSER_PATH='C:/полный/путь/к/browser.exe'
```

Чтобы узнать путь:

1. Найдите Яндекс.Браузер или другой Chromium-браузер в меню «Пуск».
2. Откройте свойства его ярлыка.
3. На вкладке «Ярлык» скопируйте из поля «Объект» путь.
4. Вставьте этот путь в `BROWSER_PATH`.


### 2. Создать рабочий ярлык

Универсальный способ для Windows и macOS — в терминале из папки проекта выполнить:

```bash
npm run browser
```

Windows: дважды щёлкните `create-browser-shortcut.cmd`.

macOS: дважды щёлкните `create-browser-shortcut.command` в папке проекта.

На Windows создастся ярлык **«Браузер — Заказы»**. На macOS браузер сразу откроется с профилем `order-parser-profile`, который создаётся рядом с проектом автоматически.

Откройте ярлык **«Браузер — Заказы»** и один раз войдите в WhatsApp Web, Telegram Web K и VK. Входы сохранятся в отдельном рабочем профиле.

### 3. Запустить сбор заказов

Перед запуском закройте окно **«Браузер — Заказы»**, чтобы профиль не был занят другим процессом.

В терминале перейдите в папку проекта и выполните:

```powershell
npm start
```

Парсер сам откроет тот же браузерный профиль и использует сохранённые авторизации. Обычный личный браузер можно оставить открытым.

### Что создаётся автоматически

- `order-parser-profile\` — рабочий профиль браузера;
- `Браузер — Заказы.lnk` — ярлык рабочего браузера.

Эти файлы относятся к конкретному компьютеру и не должны переноситься через Git. При переносе проекта на другой компьютер укажите местный `BROWSER_PATH` и заново запустите `create-browser-shortcut.cmd` (Windows) или `create-browser-shortcut.command` (macOS).

### Справочник флагов чатов

Интерактивная таблица всех настроек чатов находится в [docs/chat-flags.html](docs/chat-flags.html). В ней можно искать чат, фильтровать по VK/WhatsApp/Telegram, видеть включённые флаги и наводить курсор на ячейки для пояснений. Данные страницы собраны из `cafes_config.json`; после изменения конфигурации страницу нужно пересоздать.

Подробная документация для будущих изменений находится в [docs/AI_PROJECT_CONTEXT.md](docs/AI_PROJECT_CONTEXT.md).
